11 — 🧠 Psychologie UX

Quelques lois utiles pour expliquer pourquoi certains patterns fonctionnent.

7 concepts
Fitts's LawPlus une cible est grande et proche, plus elle est facile à atteindre.

Application : bouton principal suffisamment grand et accessible.
Hick's LawPlus il y a de choix simultanés, plus le temps de décision augmente.

Application : limiter les actions primaires visibles.
Jakob's LawLes utilisateurs s'attendent à retrouver des conventions qu'ils connaissent déjà.

Application : navigation et composants familiers.
Recognition > RecallIl vaut mieux montrer les options que demander à l'utilisateur de les mémoriser.

Application : menus, suggestions, historique.
Progressive DisclosureMontrer d'abord l'essentiel, puis les détails au besoin.

Application : formulaires et fiches employé.
Peak-End RuleL'utilisateur se souvient particulièrement des moments forts et de la fin d'une expérience.

Application : soigner succès, erreurs et fin d'opération.
Zeigarnik EffectUne tâche commencée mais inachevée reste mentalement active.

Application : afficher les brouillons et étapes restantes.

13 — ✅ Checklist avant mise en production

Si tu peux répondre « oui » à la majorité, ta page est généralement beaucoup plus fluide.

☐ Chaque action importante a un feedback.
☐ Loading / Success / Error sont définis.
☐ Le bouton est protégé contre les doubles clics.
☐ Les erreurs expliquent quoi faire.
☐ Les données saisies ne sont pas perdues.
☐ Les listes ont un Empty State.
☐ Les recherches utilisent un debounce si nécessaire.
☐ Les filtres et la pagination sont conservés.
☐ Il n'y a pas de reload complet inutile.
☐ Les actions destructives sont claires.
☐ Les actions réversibles peuvent utiliser Undo.
☐ Le mobile a une vraie adaptation.
☐ Le clavier permet les actions principales.
☐ Le focus est visible.
☐ Les couleurs ne sont pas le seul moyen d'information.
☐ Les textes, boutons et espacements suivent un système cohérent.
☐ L'utilisateur sait toujours où il se trouve.
☐ L'état de synchronisation est compréhensible.
☐ Les opérations longues affichent une progression si pertinent.
☐ J'ai testé le parcours avec un utilisateur réel.
